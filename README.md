# Phantom info
> Note that only the Anti-AFK script works on mobile as there is no gui and I don't like coding compatability.
## Anti-AFK
Loadstring:
```loadstring(game:HttpGet("https://raw.githubusercontent.com/outtee15/Phantom/refs/heads/main/AntiAFK.lua"))()```
A fully open sourced script to prevent getting kicked for that annoying "Idle for 20 minutes." The best option put the lua file in an Auto-Execution folder and since it has no GUI it will run in the background but not overlap since precautions are taken for that.
